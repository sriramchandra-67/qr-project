# QR Project

A Python tool that turns links into QR codes and reads links back from QR images.

## Features
- Link to QR code (saved as my_qr.png)
- QR code to link (reads any QR image)

## How to run
1. Install Python 3.
2. Install the libraries:
   pip install "qrcode[pil]" opencv-python
3. Run the program:
   python qr_project.py

## Built with
- Python
- qrcode
- OpenCV
